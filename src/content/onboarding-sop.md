# ALCOR NORTH STAR — CLIENT ONBOARDING SOP

## Purpose
This is the complete Sales & Marketing Client Onboarding workflow for Alcor Getaways. The BD team uses it to make every new hotel/resort client digitally ready, collect required information/assets, activate purchased pipelines, assign managers, and complete internal handover.

## 1. SERVICE MODEL — FIRST DECISION

When BD clicks **New Client Onboarding**, first ask:

### A. SINGLE PIPELINE
Client has purchased one service.

Available pipelines:
1. Performance Marketing — Google Ads, Meta Ads
2. Social Media — Instagram, Facebook, YouTube, LinkedIn
3. Google Business Profile — NAP Audit, Monthly Growth Tracker
4. Influencer Marketing
5. B2B Connect
6. WhatsApp Marketing
7. OTAs

**Rule:** Show only requirements relevant to the selected pipeline.

### B. ALCOR FUNNEL PACKAGE
Client has purchased the multi-pipeline package.

Default pipelines:
- Performance Marketing
- Social Media
- Google Business Profile
- Influencer Marketing
- B2B Connect
- WhatsApp Marketing
- OTAs

BD can add/remove pipelines according to the signed agreement.

## 18. ONBOARDING COMPLETION

Show a progress bar, e.g. **82%**.

Breakdown:
- Client Information
- Documents
- Assets
- Access
- Pipeline Setup
- Manager Allocation
- Handover

Mandatory requirements must be complete before status can become Complete.

## 19. STATUS WORKFLOW

**New → Information Pending → Documents Pending → Access Pending → Pipeline Setup → Team Allocation → Ready for Handover → Handover Complete → Onboarding Complete**

Admin may override with an audit log.

## 20. CLIENT PENDING

BD can mark an item **CLIENT PENDING** when waiting for the hotel, such as images, access, rates, agreement or payment proof.

This must distinguish client delays from Alcor delays.

## 21. BD DASHBOARD

Show:
- New Clients

- Information Pending
- Documents Pending
- Client Pending
- Access Pending
- Ready for Handover
- Completed

Client card:

## 22. REMINDERS

Generate reminders for missing agreement, NOC, payment proof, GBP access, social access, logo, images, videos, rate sheet and incomplete integrations.

## 23. AUDIT TRAIL

Record:
- User
- Date
- Time
- Action

- New Status

## 24. ADMIN CONFIGURATION

Admin can add/edit:
- Client fields
- Documents
- Pipelines
- Managers
- Mandatory/optional requirements
- Packages
- Stages
- KPI requirements
- Checklist items

Do not hard-code the onboarding engine.

## 25. SECURITY

Use role-based access. Secure sensitive credentials. Clients must never see internal notes. Prefer delegated account permissions. Maintain audit logs.

## 26. DESIGN

Premium Alcor Getaways style:
**Navy Blue + White + Gold**

Use simple forms, progress indicators, checklists, status badges, easy uploads, minimal clutter and responsive layouts.

Clearly label:
**MANDATORY / OPTIONAL / CLIENT PENDING / INTERNAL ACTION / COMPLETE**

## FINAL BUSINESS RULE

Always start with:

**WHAT DID THE CLIENT BUY?**

**SINGLE PIPELINE:** collect and configure only what that pipeline requires.

**ALCOR FUNNEL PACKAGE:** run the complete multi-pipeline onboarding workflow, with BD able to adjust active pipelines according to the signed agreement.

The final objective is:

**RIGHT CLIENT DATA → RIGHT ACCESS → RIGHT PIPELINES → RIGHT MANAGERS → RIGHT SETUP → RIGHT HANDOVER → READY FOR BUSINESS**
